Built-in MCP server · soon

One sentence to Claude, one feature ready.

Hublot ships with an MCP server. Ask Claude for a feature: it arrives with all its issues, filled in with the same fields as guided creation, and checked before it enters GitHub.

  • Claude acts with your permissions, no more, no less.
  • Something missing? Hublot says so, and Claude asks you.
  • Drafts by default: nothing enters GitHub without your approval.
  • Every action is logged “via Claude”.

terminal

claude mcp add --transport http hublot [YOUR INSTANCE]/mcp

“Create the Excel export of orders for the online shop, split into ready issues.”

Questions

Do my colleagues need a GitHub account?

No. They sign in with their work e-mail. Only developers use GitHub.

Can they see our code?

No. They only see requests for the products you give them access to.

What happens if we stop using Hublot?

Nothing is lost: everything is already in GitHub.
